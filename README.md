# Фото в отзывах WooCommerce

Плагин позволяет покупателям прикреплять до 5 фотографий к отзывам на товары WooCommerce.

Изображения сохраняются в медиатеке WordPress и отображаются под текстом отзыва в виде превью. По клику фотография открывается поверх страницы. Изображения одного отзыва можно перелистывать с помощью стрелок.

## Возможности

- До 5 фотографий на один отзыв.
- Максимальный размер одного файла — 2 МБ.
- Поддерживаемые форматы: JPG, PNG, WebP.
- Автоматическое сохранение изображений в медиатеку WordPress.
- Привязка загруженных изображений к конкретному отзыву.
- Отображение превью под текстом отзыва.
- Увеличение фотографии по клику.
- Перелистывание фотографий внутри одного отзыва.
- Просмотр без сторонних JavaScript-библиотек.

## Установка

1. Скачайте плагин и распакуйте архив.
2. Поместите папку `woo-review-photos` в каталог `wp-content/plugins/`.
3. В админке WordPress откройте раздел «Плагины» и активируйте плагин.
4. Убедитесь, что WooCommerce установлен и активирован.

## Использование

1. Откройте страницу товара WooCommerce.
2. Напишите отзыв и прикрепите до 5 фотографий.
3. Отправьте отзыв.
4. После публикации отзыва фотографии появятся под его текстом.

Если на сайте включена предварительная модерация комментариев, фотографии станут видны после одобрения отзыва администратором.

## Ограничения

- Максимум 5 изображений на один отзыв.
- Максимальный размер одного изображения — 2 МБ.
- Поддерживаются только JPG, PNG и WebP.
- Загруженные изображения сохраняются в медиатеке WordPress.
- Галерея работает только на страницах товаров WooCommerce.

## Требования

Плагин требует установленный и активированный WooCommerce.

Рекомендуется использовать актуальные версии WordPress, WooCommerce и PHP.

Совместимость подтверждена только на версиях, на которых плагин был протестирован автором.

## Безопасность

Плагин ограничивает количество и размер загружаемых файлов, а также разрешает загрузку только поддерживаемых форматов изображений.

Перед использованием на рабочем сайте рекомендуется сделать резервную копию файлов и базы данных WordPress.
